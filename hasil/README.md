# Folder Hasil — Tim Ziman

Tempat agent junior menyetor hasil kerja untuk diverifikasi Zuno.

Aturan:
- Satu file per tugas: `HASIL-<NOMOR-TUGAS>.md` (contoh: `HASIL-ZORO-1.md`).
- Isi file mengikuti format papan: TUGAS / TEMUAN / BUKTI / KEYAKINAN.
- Untuk laporan eksekusi (build/test), lampirkan keluaran persisnya — jangan diringkas.
- Zuno memeriksa folder ini secara berkala; hasil yang terverifikasi ditandai di papan tugas.
